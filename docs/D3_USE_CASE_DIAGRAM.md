D3: Diagram Use Case Menferse

1. Tujuan

Diagram use case Menferse menggambarkan interaksi antara aktor dan fungsi utama sistem. Diagram ini digunakan untuk menjelaskan batas sistem serta fitur yang dapat diakses oleh mahasiswa dan administrator.

2. Aktor

Mahasiswa

Mahasiswa dapat melihat menfess yang telah disetujui, masuk ke akun, mengirim menfess, memilih identitas pengirim, melihat katalog bunga, memesan bunga, dan melihat status pesanan.

Administrator

Administrator bertugas memeriksa pesan menfess serta menyetujui atau menolak pesan sebelum ditampilkan pada halaman utama.

3. Daftar Use Case

1. Melihat Menfess
2. Masuk ke Akun
3. Mengirim Menfess
4. Memilih Identitas Pengirim
5. Memeriksa Menfess
6. Menyetujui Menfess
7. Menolak Menfess
8. Melihat Katalog Bunga
9. Memesan Bunga
10. Mengisi Data Penerima
11. Melihat Status Pesanan

4. Hubungan Antar-Use Case

- Mengirim Menfess menyertakan proses pemilihan identitas pengirim melalui hubungan "<<include>>".
- Memesan Bunga menyertakan proses pengisian data penerima melalui hubungan "<<include>>".
- Menyetujui Menfess dan Menolak Menfess merupakan perilaku tambahan dalam proses pemeriksaan menfess melalui hubungan "<<extend>>".

5. Kesimpulan

Diagram use case ini menunjukkan fungsi utama Menferse serta hubungan antara mahasiswa, administrator, dan sistem. Diagram menjadi acuan untuk menyusun diagram sequence yang menggambarkan urutan interaksi pada skenario utama.
